# 🔐 Passwordium

A modern desktop password strength analyzer built with Python and CustomTkinter.

Passwordium analyzes passwords and provides a security score, estimated entropy, strength rating, and security recommendations.

## ✨ Features

- 🔐 Password strength analysis
- 🛡️ Security score from 0–100
- 📊 Estimated password entropy
- 🔤 Checks for uppercase and lowercase letters
- 🔢 Detects numbers
- ⚡ Detects special characters
- 🚨 Detects common password patterns
- 🔍 Detects predictable number sequences
- 👁️ Show or hide password
- 🧹 Clear password button
- 💡 Security recommendations
- 🌐 Direct link to the developer's GitHub profile
- 🎨 Modern cybersecurity-inspired interface
