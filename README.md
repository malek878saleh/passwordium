# Passwordium 🔐

Developed By: Malek F Saleh 

A simple desktop password manager built with Python.

![Passwordium Screenshot](screenshot.png)

## Features

- 🔐 Password management
- 🔑 Password generation
- 💾 Local password storage
- 🖥️ Desktop interface
- 📝 Simple and easy to use

## Requirements

- Python 3.x
- Dependencies listed in `requirements.txt`
